Sistema de Gestión de Tareas

API desarrollada con Python y Flask para registrar usuarios, validar credenciales y mostrar una página HTML de bienvenida. Incluye un cliente de consola y utiliza SQLite para almacenar los usuarios de forma persistente.

Sobre el proyecto

Este trabajo forma parte del Proyecto Final Obligatorio 2 (PFO2). Consiste en una API desarrollada con Python y Flask, acompañada de un cliente de consola. El sistema permite registrar usuarios, validar sus credenciales y conservar la información en SQLite.

Alcance actual

El endpoint /tareas muestra una página HTML estática de bienvenida. Esta versión todavía no implementa operaciones para crear, editar, eliminar o listar tareas almacenadas.

Endpoints de la API

Rutas disponibles en el servidor Flask.

GET /

Devuelve el mensaje de bienvenida y el estado del servidor.

POST /registro

Registra usuarios en la base de datos SQLite.

POST /login

Valida las credenciales del usuario.

GET /tareas

Muestra una página HTML estática de bienvenida.
